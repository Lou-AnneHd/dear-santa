# Dear Santa, I Got Carried Away.

## Installation

1. Le fichier original `assets/santa_sleigh.json` est inclus. Animation de Rocío Lezcano : https://lottiefiles.com/free-animation/santa-sleigh-S9p5Oa4vIP. Transparence des images intégrées vérifiée ; aucun détourage nécessaire.
2. La photo originale du vinyle est chargée depuis la Fnac dans le navigateur. Pour une copie locale facultative, enregistrer https://static.fnac-static.com/multimedia/Images/FR/NR/b3/ab/b1/11643827/1540-1/tsp20200123145106/Les-Failles-Cachees.jpg sous `assets/cover.jpg`.
3. `pip install -r requirements.txt`
4. `streamlit run app.py`

Pour Streamlit Community Cloud, déposer les fichiers (y compris .streamlit et assets) dans un dépôt GitHub et choisir app.py.
